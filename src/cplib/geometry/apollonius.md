# アポロニウスの軌跡

`apollonius_locus(a, b, ratio)` は `|P-a| = ratio * |P-b|` を満たす点の集合を返す。
`Point` は `geometry/base`、`Circle` とその `center` / `radius` は依存PR #946 の `geometry/circle` を使用する。利用側で必要なモジュールを import する。
時間・追加空間ともに O(1)。配列確保やI/Oは行わない。

- `apolloniusCircle`: `circle` に円周を格納する。半径0は一点。
- `apolloniusLine`: `linePoint + t * lineDirection`（実数 t）で垂直二等分線を表す。方向は単位ベクトル。巨大な基準点に単位方向を加えると同一点に丸められるため、二点による直線表現を使わない。
- `apolloniusPlane`: 全平面。

比0では点a、同一点では比1なら全平面、それ以外ならその一点となる。
異なる二点で比1なら垂直二等分線、それ以外なら円周となる。
入力座標と比は演算前にfloat64へ変換し、その後の成分の厳密比較で分類する。既存のPoint比較やGEOMETRY_EPSには依存しない。

距離の二乗の等式を展開すると、比rが1以外のとき中心は `(a-r²*b)/(1-r²)`、半径は `r*|b-a|/|1-r²|`。
実装ではr<1なら `a-(b-a)*r²/((1-r)(1+r))`、r>1なら `b+(b-a)/(r²-1)` を使う。
分母を因数分解し、r>1では逆数を使ってr²のオーバーフローを避ける。
ベクトル長も最大成分で正規化してから計算する。

座標と比は有限、比は非負である必要がある。座標差・距離・中間値・出力はfloat64で表現可能な範囲を前提とする。
検出できた非有限値と、異なる二点・正の比で半径が0へアンダーフローする場合はValueError。
すべてのアンダーフローや桁落ちは検出しない。整数が2^53を超える場合やfloat32入力では、変換前の区別や精度を復元できない。

比は厳密に1のときだけ直線となる。1に近い比をEPSで丸めない。
比が1に近いと中心・半径が大きくなり、比の入力誤差は概ね `1/|1-r|` に比例して増幅される。
非常に大きな平行移動、小さな半径、極端な尺度差では精度を失う。厳密な幾何述語、正しい丸め、任意精度は保証しない。

検証は `src/verify/AI/apollonius_test.nim`。整数係数の独立oracle、円周上の距離比残差、対称性、境界・退化・尺度を確認する。
